Bagian 02

Wireless Terminology

SSID, BSSID, Hotspot — istilah dasar yang harus dipahami sebelum mendalami wireless security.

📡
SSID — Service Set Identifier

32-alphanumeric-character unique identifier yang identifies wireless network. SSID mengizinkan connections ke desired network among available networks. Devices connecting ke same WLAN harus use same SSID.

🔖
BSSID — Basic Service Set Identifier

MAC address dari access point (AP). Setiap AP di network punya BSSID unik. BSSID = hardware identifier — tidak sama dengan SSID yang adalah logical name.

📶
Hotspot

Places di mana wireless networks available untuk public use. Hotspots = areas with Wi-Fi availability, di mana users dapat enable Wi-Fi di devices mereka dan connect ke internet.

📡
Access Point (AP)

Device yang menghubungkan wireless clients ke wired network. AP bertindak sebagai central hub untuk wireless communication. Membroadcast SSID agar clients dapat discover dan connect.

Bagian 03

802.11 Wireless Standards

6 standar Wi-Fi dari 802.11a (1999) hingga 802.11ax / Wi-Fi 6 (2019).

Wireless Fidelity (Wi-Fi) menggunakan standard 802.11 dan radio waves untuk communication. Wireless networking merevolusi cara orang bekerja dan bermain. Wireless networking sangat berguna di public places termasuk libraries, coffee shops, hotels, airports.

802.11 Standards Evolution — dari a (1999) ke ax/Wi-Fi 6 (2019)
Gambar 2. 802.11 standards evolution — dari 11 Mbps (802.11b) hingga 9.6 Gbps (Wi-Fi 6).

3.1 Advantages & Disadvantages

✓Advantages

  • Mobility — access network dari mana pun dalam range
  • Easy installation — no cabling needed
  • Scalability — easy add new devices
  • Cost-effective — less wiring infrastructure
  • Flexibility — devices can roam

−Disadvantages

  • Security risks — RF signal bleeds beyond walls
  • Interference — electronic equipment disrupts
  • Slower than wired (shared medium)
  • Range limitations — signal degrades with distance
  • Wi-Fi upgrades may require new cards/APs
Bagian 04

Wireless Network Components

AP, wireless router, wireless client — building blocks dari wireless network.

📡
Access Point (AP)

Device yang connects wireless clients ke wired network. Broadcasts SSID, manages associations, bridges wireless ↔ wired. Can be autonomous (standalone config) atau lightweight (controller-managed).

🔌
Wireless Router

Combines AP + router + switch + firewall in single device. Common di home/small office. Provides NAT, DHCP, firewall, port forwarding. Consumer-grade — enterprise gunakan separate components.

💻
Wireless Client

Device dengan wireless adapter — laptop, smartphone, tablet, IoT device. Connects ke AP via SSID. Modern devices support multiple standards (a/b/g/n/ac/ax).

4.1 Wireless Topologies

🔄
Ad-Hoc Mode (IBSS)

Peer-to-peer — wireless clients connect langsung ke each other tanpa AP. Setiap node = router. Use case: file sharing antar laptop, temporary network. Security risk: no central control, difficult to secure.

⭐
Infrastructure Mode (BSS/ESS)

Clients connect ke central AP yang bridging ke wired network. BSS = single AP. ESS = multiple APs dengan same SSID (roaming). Standard enterprise topology. Easier to secure via AP.

Bagian 05

Wireless Encryption Mechanisms

WEP → WPA → WPA2 → WPA3 — evolusi enkripsi Wi-Fi dari broken ke secure.

4 Generations Wi-Fi Encryption — dari WEP (broken) ke WPA3 (secure)
Gambar 3. 4 generations Wi-Fi encryption — WEP (broken) → WPA (interim) → WPA2 (current min) → WPA3 (latest, secure).
Warning: WEP dapat di-crack dalam 2-5 menit menggunakan tools seperti Aircrack-ng. JANGAN PERNAH menggunakan WEP. WPA (TKIP) juga deprecated. Minimum yang aman: WPA2 dengan AES-CCMP. Idealnya: WPA3. Jika device tidak support WPA2+, ganti device tersebut.
Bagian 06

Wireless Authentication Methods

3 jenis autentikasi: Open System, Shared Key, dan WPA-Enterprise (802.1X/EAP).

🔓
Open System Authentication

No authentication — any client can connect. Hanya identify via SSID. Zero security. Use case: public hotspot, guest network (dengan captive portal). Tidak boleh untuk corporate network.

🔑
Shared Key Authentication (WEP)

Client dan AP share same WEP key. AP sends challenge text, client encrypts with key, AP verifies. VULNERABLE — challenge-response leaks key bits. Lebih insecure dari Open System! Deprecated.

🏢
WPA-Enterprise (802.1X/EAP)

Enterprise-grade: RADIUS server + individual credentials per user. EAP methods: EAP-TLS (certificate), PEAP (MS-CHAPv2 inside TLS), EAP-TTLS. Most secure untuk enterprise. Each user = unique credential.

6.1 WPA Personal vs Enterprise

🏠
WPA-Personal (PSK)

Pre-Shared Key — same passphrase shared among all users. Simple setup. Kelemahan: jika 1 orang leave, semua harus ganti password. Tidak ada individual accountability. Cocok: home, small office.

🏢
WPA-Enterprise (802.1X)

Individual credentials per user via RADIUS. Setiap user login dengan username/password sendiri (atau certificate). Jika 1 orang leave, revoke 1 account saja. Audit trail per user. Cocok: enterprise, campus.

Bagian 08

Wireless Security Measures

Best practices untuk secure wireless network di enterprise.

🔐
Use WPA3 (or WPA2 minimum)

WPA3 dengan SAE = latest secure standard. Jika device tidak support WPA3, gunakan WPA2-AES. JANGAN WEP atau WPA-TKIP. Disable mixed mode jika memungkinkan.

🔑
802.1X Enterprise Authentication

Gunakan RADIUS + EAP-TLS/PEAP untuk individual user credentials. Setiap user login dengan account sendiri. Revocation mudah saat employee leave.

🛡
WIDS/WIPS

Wireless Intrusion Detection/Prevention System — detect rogue AP, evil twin, deauth attacks. Continuous monitoring wireless spectrum. Examples: AirWave, Cisco WLC, Aruba ClearPass.

📡
Disable WPS

WPS (Wi-Fi Protected Setup) vulnerable to brute-force (PIN = 8 digit, dapat di-crack dalam jam). Disable WPS di semua AP — termasuk consumer router.

🌐
Network Segmentation

Wireless network di VLAN terpisah dari wired network. Guest Wi-Fi di isolated VLAN — internet access only, no access ke corporate network.

🔒
VPN for Guest Access

Untuk akses corporate network via wireless, require VPN tunnel. Wireless = untrusted network. VPN = encrypted tunnel ke corporate.

Bagian 09

Wireless Security Tools

Tools untuk audit, monitor, dan test wireless network security.

📡
Aircrack-ng Suite

Complete toolset untuk wireless security assessment: airmon-ng (monitor mode), airodump-ng (packet capture), aireplay-ng (deauth/injection), aircrack-ng (WEP/WPA key crack). De facto standard.

🔍
Kismet

Wireless network detector & sniffer — passive scan (tidak broadcast). Detect hidden SSID, rogue AP. Supports 802.11 a/b/g/n/ac. GPS integration untuk war driving mapping.

📊
Wireshark

Packet capture & analysis. Dengan monitor mode WiFi adapter, dapat capture wireless management frames (beacons, probes, deauth). Decode WPA handshake. Essential untuk wireless forensics.

🛡
Wifite / Fluxion

Automated wireless attack tools. Wifite: automated WEP/WPA crack. Fluxion: evil twin + captive portal untuk credential harvest. Gunakan hanya di lab/sendiri — illegal di jaringan orang lain.

Bagian 10 · Hands-on Lab

Modul Praktikum Wireless Security

Empat sesi praktik hands-on: wireless network discovery, WPA2 handshake capture, evil twin simulation, dan wireless security audit dengan hardening.

10.1 Tujuan Praktikum

1
Network Discovery

Discover dan map wireless networks di area lab menggunakan Kismet dan airodump-ng — identifikasi SSID, BSSID, encryption, signal strength.

2
WPA2 Handshake Capture

Capture WPA2 4-way handshake menggunakan aircrack-ng suite — lalu attempt offline crack dengan wordlist.

3
Evil Twin Simulation

Setup evil twin AP dengan same SSID sebagai lab AP — demonstrate risk dan mitigasi (certificate validation).

4
Wireless Audit & Hardening

Audit wireless network security — identify misconfigurations, implement hardening (WPA3, 802.1X, WIDS).

10.2 Alat dan Bahan

💻Perangkat Keras

  • Laptop dengan WiFi adapter yang support monitor mode (Alfa AWUS036ACH, TP-Link TL-WN722N v1)
  • Wireless router/AP lab (yang Anda miliki — untuk testing)
  • 2 VM: Kali Linux (attacker) + Ubuntu (client)
  • Optional: Raspberry Pi untuk evil twin AP

🧰Perangkat Lunak

  • Kali Linux (pre-installed wireless tools)
  • Aircrack-ng suite (airmon, airodump, aireplay, aircrack)
  • Kismet untuk passive wireless discovery
  • Wireshark untuk packet analysis
  • hostapd + dnsmasq untuk evil twin AP
  • hashcat untuk GPU-accelerated WPA crack (opsional)
  • Wordlist: rockyou.txt
PERINGATAN LEGAL: Lakukan praktik HANYA pada wireless network yang Anda miliki atau punya izin tertulis. Meng-capture traffic, crack password, atau setup evil twin di jaringan orang lain TANPA izin adalah ILEGAL di hampir semua yurisdiksi (UU ITE Pasal 30 & 33 di Indonesia, Computer Fraud and Abuse Act di US). Gunakan AP lab sendiri.

10.3 Workflow Praktikum 4 Sesi

Alur Praktikum — 4 Sesi, 20 Langkah, 1 Laporan Akhir
Gambar 5. Workflow 4 sesi praktikum Modul 07 — total 20 langkah hands-on.

10.4 Langkah Praktikum

Sesi 1 — Wireless Network Discovery

1
Enable Monitor Mode

Di Kali Linux, identify WiFi adapter: iwconfig. Enable monitor mode: airmon-ng start wlan0. Verifikasi: iwconfig — interface berubah ke wlan0mon mode=Monitor.

2
Discover Networks dengan airodump-ng

Run: airodump-ng wlan0mon. Tunggu 30 detik. Catat: BSSID, SSID, channel, encryption (WEP/WPA/WPA2/WPA3), signal strength (PWR), number of clients. Identifikasi AP lab Anda di list.

3
Targeted Capture

Target AP lab: airodump-ng -c <channel> --bssid <BSSID> -w capture wlan0mon. Tunggu 2-3 menit. Catat: connected clients (station MAC), data packets captured. File capture-01.cap tersimpan.

4
Kismet Passive Discovery

Install Kismet: apt install kismet. Run: kismet -c wlan0mon. Buka browser ke http://localhost:2501. Kismet melakukan passive scan — tidak broadcast probe requests. Bandingkan hasil dengan airodump-ng.

5
Map & Laporan

Buat map wireless landscape: AP count per channel (identify crowded channels), encryption distribution (berapa % WPA2 vs WPA3 vs WEP), signal heatmap. Rekomendasi: channel optimization, upgrade encryption. Laporan: discovery results + security assessment.

Sesi 2 — WPA2 Handshake Capture & Crack

1
Capture WPA2 Handshake

Target AP lab (WPA2-PSK). Start capture: airodump-ng -c <ch> --bssid <BSSID> -w wpa2_capture wlan0mon. Tunggu client connect — atau force deauth: aireplay-ng --deauth 5 -a <BSSID> -c <client_MAC> wlan0mon. Capture handshake (muncul "WPA handshake: <MAC>" di airodump).

2
Verify Handshake di Wireshark

Buka wpa2_capture-01.cap di Wireshark. Filter: eapol. Identifikasi 4 EAPOL frames (4-way handshake): Message 1-4. Verifikasi: handshake lengkap = crackable. Jika tidak lengkap, ulang deauth + capture.

3
Dictionary Attack dengan aircrack-ng

Crack: aircrack-ng -w /usr/share/wordlists/rockyou.txt wpa2_capture-01.cap. Jika password ada di wordlist → cracked dalam menit. Catat: waktu yang diperlukan, password yang recovered.

4
Hashcat (GPU) — Opsional

Konversi capture ke hashcat format: hcxtools/hcxpcaptool -o hash.hccapx wpa2_capture-01.cap. Crack dengan hashcat: hashcat -m 22000 hash.hccapx rockyou.txt. Bandingkan speed: aircrack-ng (CPU) vs hashcat (GPU).

5
Laporan & Mitigasi

Laporan: (a) handshake capture screenshot, (b) crack results (password recovered/tidak), (c) time comparison CPU vs GPU, (d) mitigasi: gunakan strong passphrase (16+ char, tidak di wordlist), WPA3-SAE (resistant to offline crack), 802.1X Enterprise (no shared key).

Sesi 3 — Evil Twin Simulation

1
Setup Evil Twin AP

Di Kali Linux, install hostapd + dnsmasq. Config hostapd dengan same SSID sebagai lab AP, same channel. Config dnsmasq untuk DHCP. Enable IP forwarding + NAT. Start: hostapd hostapd.conf + dnsmasq -C dnsmasq.conf.

2
Deauth Legitimate AP

Force client disconnect dari legitimate AP: aireplay-ng --deauth 0 -a <legit_BSSID> wlan0mon (continuous deauth). Client akan auto-connect ke evil twin (same SSID, stronger signal). Verifikasi: client connected ke evil twin.

3
Capture Client Traffic

Saat client connected ke evil twin, capture traffic: tcpdump -i <ap_interface> -w evil_twin_traffic.pcap. Client browse HTTP site → traffic visible di plaintext. Demonstrasi: evil twin dapat intercept all traffic.

4
Captive Portal (Optional)

Setup captive portal (nginx + PHP) yang mimic login page. Client connect → redirect ke portal → enter credentials. Pelajaran: ini adalah cara attacker harvest credentials di public Wi-Fi. Screenshot: captive portal + credential capture.

5
Mitigasi & Laporan

Mitigasi evil twin: (a) WPA3-Enterprise dengan certificate validation — client verify server cert, reject fake AP, (b) VPN tunnel — encrypt all traffic, evil twin hanya lihat encrypted, (c) WIDS untuk detect unauthorized AP. Laporan: evil twin setup + attack demo + mitigasi.

Sesi 4 — Wireless Audit & Hardening

1
Audit Lab AP Configuration

Login ke admin panel AP lab. Audit: (a) encryption type (WEP/WPA/WPA2/WPA3), (b) WPS enabled/disabled, (c) SSID broadcast (hidden/visible), (d) admin password (default/custom), (e) firmware version (latest?), (f) guest network isolation, (g) MAC filtering, (h) TX power (range control).

2
Identify Misconfigurations

Checklist: WEP/WPA-TKIP enabled? WPS on? Default admin password? Firmware outdated? Guest network can access LAN? SSID broadcast unnecessary? TX power too high (signal bleeds)? Document setiap misconfiguration dengan risk level.

3
Implement Hardening

Fix: (a) upgrade ke WPA2-AES minimum (WPA3 jika supported), (b) disable WPS, (c) change admin password (16+ char), (d) update firmware, (e) enable guest network isolation, (f) reduce TX power (signal stays dalam building), (g) disable remote admin dari WAN.

4
Enterprise Security (If Available)

Jika punya RADIUS server (FreeRADIUS dari Modul 02): setup WPA2-Enterprise (802.1X/EAP-PEAP). Test: client connect dengan individual username/password. Verifikasi: handshake terenkripsi, no shared PSK. Compare security dengan PSK mode.

5
Final Audit & Laporan

Re-audit setelah hardening. Compare before vs after. Buat laporan: (a) audit checklist (before/after), (b) hardening actions, (c) enterprise auth setup (if done), (d) security posture improvement, (e) recommendations: WIDS/WIPS deployment, periodic audit schedule, wireless policy.

10.5 Lembar Kerja / Tugas

Q1
WEP vs WPA3

Mengapa WEP dapat di-crack dalam menit? Apa improvement utama WPA3 dibanding WPA2? Mengapa WPA3-SAE resistant terhadap offline dictionary attack?

Q2
Evil Twin Risk

Dari Sesi 3, jelaskan bagaimana evil twin attack bekerja. Mengapa client auto-connect ke evil twin? Bagaimana WPA3-Enterprise mencegah evil twin? Apa mitigasi lain selain WPA3?

Q3
WPA2-PSK vs Enterprise

Bandingkan WPA2-PSK (Personal) vs WPA2-Enterprise (802.1X). Kapan menggunakan masing-masing? Apa kelemahan PSK di enterprise? Bagaimana 802.1X mengatasi kelemahan tersebut?

Q4
Deauth Attack

Apa itu deauthentication attack? Mengapa serangan ini efektif? Bagaimana WPA3 mengurangi risiko deauth? Apa mitigasi lain (selain WPA3)?

Q5
Wireless Audit

Dari Sesi 4, apa 3 misconfiguration paling berbahaya yang ditemukan? Mengapa WPS berbahaya? Mengapa TX power control penting untuk security?

Q6
Defense-in-Depth Wireless

Berdasarkan modul, jelaskan defense-in-depth untuk wireless: encryption + authentication + WIDS + segmentation + VPN. Apa yang terjadi jika salah satu dihilangkan?

10.6 Checklist Evaluasi

Praktikum dinyatakan lulus jika minimal 10 dari 12 kriteria berikut terpenuhi:

  • Monitor mode WiFi adapter berhasil di-enable
  • airodump-ng menemukan minimal 5 wireless networks
  • Kismet passive discovery terdokumentasi dengan screenshot
  • WPA2 handshake berhasil di-capture (4 EAPOL frames)
  • aircrack-ng dictionary attack berhasil crack password lab (jika weak)
  • Wireshark analysis handshake terdokumentasi
  • Evil twin AP berhasil di-setup dengan same SSID
  • Client berhasil di-force connect ke evil twin
  • Evil twin traffic capture menunjukkan intercepted data
  • Wireless audit checklist lengkap (before hardening)
  • Minimal 5 hardening actions terimplementasi (WPA2/3, WPS off, dll)
  • Final audit menunjukkan improvement (before vs after)
Bonus: Mahasiswa yang dapat mendemonstrasikan: (a) WPA3-SAE setup dan test resistance terhadap offline crack, (b) 802.1X Enterprise dengan FreeRADIUS + EAP-TLS certificate, (c) WIDS deployment menggunakan Kismet alerting, atau (d) PMKID attack (clientless WPA2 crack tanpa handshake) — akan mendapat nilai tambahan.
Bagian 11

Ringkasan Modul

Rangkuman poin-poin kritis yang telah dibahas dalam Modul 07 Wireless Network Security.

📋 Yang Telah Dipelajari

  • Wireless terminology — SSID (network name), BSSID (AP MAC), Hotspot (public Wi-Fi), AP (access point).
  • 802.11 standards — a (5GHz, 54Mbps), b (2.4GHz, 11Mbps), g (2.4GHz, 54Mbps), n/Wi-Fi 4 (dual-band, 600Mbps), ac/Wi-Fi 5 (5GHz, 3.5Gbps), ax/Wi-Fi 6 (tri-band, 9.6Gbps, WPA3).
  • Wireless components — AP (bridges wireless↔wired), wireless router (AP+router+switch+firewall), wireless client (laptop, phone, IoT).
  • Wireless topologies — Ad-Hoc (peer-to-peer, no AP) vs Infrastructure (BSS/ESS, central AP).
  • 4 encryption generations — WEP (RC4, broken in minutes), WPA (RC4+TKIP, interim), WPA2 (AES-CCMP, current minimum, KRACK vulnerable), WPA3 (AES-256+GCMP+SAE, latest, offline-crack resistant).
  • 3 authentication methods — Open System (no auth, zero security), Shared Key (WEP, vulnerable), WPA-Enterprise/802.1X (RADIUS + EAP, individual credentials, most secure).
  • WPA Personal (PSK) vs Enterprise — PSK = shared passphrase (simple, no individual accountability), Enterprise = per-user via RADIUS (audit, revocation, enterprise-grade).
  • 8 wireless threats — Rogue AP, Evil Twin, Deauthentication, War Driving, Sniffing, Jamming, MAC Spoofing, KRACK.
  • Security measures — WPA3/WPA2 minimum, 802.1X Enterprise, WIDS/WIPS, disable WPS, network segmentation, VPN for guest access.
  • Wireless security tools — Aircrack-ng suite (airmon, airodump, aireplay, aircrack), Kismet (passive discovery), Wireshark (packet analysis), Wifite/Fluxion (automated attack).
  • Praktikum 4 sesi — Wireless Discovery (Kismet + airodump), WPA2 Handshake Capture & Crack, Evil Twin Simulation, Wireless Audit & Hardening.
Key Takeaway: Wireless networks adalah inherently less secure dari wired — RF signal bleeds beyond walls, anyone with antenna can listen. Security wireless = defense-in-depth: strong encryption (WPA3) + individual authentication (802.1X) + continuous monitoring (WIDS) + network segmentation (VLAN) + VPN tunnel. Tidak ada single control yang cukup — kombinasi semua layers diperlukan.
